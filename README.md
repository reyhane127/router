Smart Router

A learning-oriented router project focused on networking, system programming, security, and intelligent network management.

> 🚧 **Project Status:** In Development
> This project is being developed alongside learning and experimentation with Linux networking, OpenWrt, Python, and network protocols. The features below represent the planned goals of the project.

---

## 🎯 Project Goals

The main goal of this project is to build a feature-rich and intelligent router while gaining practical experience in **network programming, Linux networking, routing, security, and system-level development**.

### 1. 🌐 Network Optimization

#### Smart QoS

Develop a system that can analyze network traffic and intelligently prioritize latency-sensitive traffic such as:

* 🎥 Video calls
* 🎮 Online gaming
* 📞 Real-time communication

The goal is to reduce latency, packet loss, and network congestion.

#### Load Balancing & Failover

Support multiple Internet connections and intelligently manage them by:

* ⚖️ Distributing traffic across multiple links
* 🔄 Automatically switching to a backup connection when the primary link fails
* ❤️ Monitoring link health and availability
* 🚀 Restoring the primary connection when it becomes available again

---

### 2. 🔐 Security & Privacy

#### Router-Level VPN

Implement VPN client and server functionality directly on the router using technologies such as:

* WireGuard
* OpenVPN

This allows connected devices to use the secure tunnel without requiring separate VPN software on each device.

#### 🛡️ Network-Wide Ad Blocking

Implement a network-wide advertisement and tracking blocker so that connected devices can benefit from filtering without installing additional software.

#### 🔥 Advanced Firewall & Monitoring

Develop firewall and monitoring capabilities for:

* Traffic filtering
* Access control
* Connection monitoring
* Suspicious traffic detection
* Network activity analysis

---

### 3. 🧠 Smart Management & User Experience

#### 🖥️ Modern Web Dashboard

Develop a modern web-based interface for managing and monitoring the router, including:

* Network status
* Connected devices
* Traffic statistics
* Link health
* Routing information
* System configuration

#### 👨‍👩‍👧 Parental Control

Provide tools for managing and controlling network access, including:

* Website and content filtering
* Device-based access control
* Scheduling Internet access
* Usage monitoring

#### 👤 Guest Portal

Provide a dedicated guest network and captive portal for guest users.

#### 📡 IoT Hub

Extend the router into an IoT management hub capable of managing and monitoring connected IoT devices.
